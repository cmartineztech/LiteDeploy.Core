## 🚀 `LiteDeploy.SetDeploymentShareAcl.ps1`

### Overview

`LiteDeploy.SetDeploymentShareAcl.ps1` automates the provision and security hardening of a LiteDeploy deployment share. It establishes a secure folder structure, creates local service accounts if necessary, configures SMB share permissions, and applies granular NTFS Access Control Lists (ACLs) to ensure isolated write operations for client deployment logs.

### Key Features

- **Automated Directory Provisioning**: Generates the standard directory layout:
  - `<SharePath>\Engine` — Stores deployment engine files and assets (Read & Execute).
  - `<SharePath>\WorkLogs\Deployments` — Destination for client execution logs (Granular write permissions).
  - The full intended share tree (Config, Content, Engine, WorkFlows, WorkLogs) is defined in [DeploymentShare](../../DeploymentShare).
- **Service Account Management**: Optionally provisions a local deployment user account (e.g., `deployer`) with non-expiring credentials.
- **SMB Share Configuration**: Re-creates or configures an SMB network share with Full Access for deployment administrators and specified identities, and Read Access for `Everyone`.
- **Granular NTFS Permission Hierarchy**:
  - **Root Share (`<SharePath>`)**: Enforces `ReadAndExecute` permissions for designated deployment users and AD groups.
  - **Logs Directory (`WorkLogs\Deployments`)**: Enforces a `CREATOR OWNER` security model. Callers can create subfolders/log files under `WorkLogs\Deployments`, but gain `FullControl` strictly over files/folders they themselves created.

## ⚙️ Parameters

| Parameter | Type | Default Value | Description |
| :--- | :--- | :--- | :--- |
| `-SharePath` | `string` | `C:\DeploymentShare` | Local file system path for the root deployment share directory. |
| `-ShareName` | `string` | `DeploymentShare$` | Name of the SMB network share created (hidden share by default). |
| `-LocalUser` | `string` | `deployer` | Local service user account to create (if missing) and authorize. Pass empty string or `$null` to skip. |
| `-AdditionalUsers` | `string[]` | `@()` | List of additional local or domain usernames to grant share and log access. |
| `-ADGroups` | `string[]` | `@()` | List of Active Directory security groups (e.g., `CORP\DeployAdmins`) to authorize. |

---

## 🔒 Security & Access Model

### 1. Root Level (`<SharePath>`)
- **Administrators**: `FullControl` (ContainerInherit, ObjectInherit)
- **Deployment Identities** (`LocalUser`, `AdditionalUsers`, `ADGroups`): `ReadAndExecute, Synchronize` (ContainerInherit, ObjectInherit)

### 2. Log Directory Level (`WorkLogs\Deployments`)
- **Administrators**: `FullControl` (ContainerInherit, ObjectInherit)
- **Deployment Identities**: `CreateFiles, CreateDirectories, Traverse, ReadAttributes` (Folder Only)
- **`CREATOR OWNER`**: `FullControl` (ContainerInherit, ObjectInherit, InheritOnly)

> [!NOTE]
> Under this model, deployment scripts running under standard client credentials can write logs to `WorkLogs\Deployments\<ComputerName>` without being able to modify or tamper with log files generated by other systems.

## 💻 Usage Examples

### Default Execution
Configures `C:\DeploymentShare` with SMB share `DeploymentShare$` and creates local user `deployer`:
```powershell
.\LiteDeploy.SetDeploymentShareAcl.ps1
```

### Custom Path, Custom Share, & AD Groups
Configures custom share location, custom SMB share name, and authorizes Active Directory groups:
```powershell
.\LiteDeploy.SetDeploymentShareAcl.ps1 `
    -SharePath "D:\LiteDeployShare" `
    -ShareName "LiteDeploy$" `
    -LocalUser "svc_deployer" `
    -ADGroups "CORP\DeployAdmins", "CORP\FieldTechs"
```

### Domain Deployment without Local Account Creation
```powershell
.\LiteDeploy.SetDeploymentShareAcl.ps1 `
    -SharePath "C:\DeploymentShare" `
    -LocalUser "" `
    -ADGroups "CORP\Domain Computers", "CORP\Helpdesk"
```

## 🛠️ Internal Functions

- **`New-LiteDeployFolderStructure`**: Generates required subfolders (`Engine`, `WorkLogs\Deployments`).
- **`New-LiteDeployLocalAccount`**: Checks for existing local user; prompts securely for password and sets `PasswordNeverExpires` if user does not exist.
- **`Set-LiteDeploySmbShare`**: Removes existing SMB share matching `-ShareName` and provisions new SMB share with defined permissions.
- **`Set-LiteDeployNtfSAcl`**: Protects NTFS inheritance and applies specific `FileSystemAccessRule` objects for root read access and log creation rules.
- **`Invoke-LiteDeployAclSetup`**: Main orchestrator function executing the setup workflow.
